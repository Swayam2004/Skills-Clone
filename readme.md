# Skills++ Clone 🌟

A clone of **Skills++**, an immersive learning platform created by **Zairza**, designed to help students elevate their expertise in various tech domains. This website was built as part of a task for the **Web Dev Intermediate** advancement by Zairza.

## Description

Skills++ is a month-long initiative designed exclusively for students at **Odisha University of Technology and Research**, offering the perfect platform to:

✅ Choose your domain  
✅ Receive guided mentoring  
✅ Complete weekly tasks  
✅ Access valuable resources

This project was an exciting journey of collaboration and learning, built by a talented team of developers:

- Suryasnat Biswal
- Utkal Kumar Das
- Rishu Singh
- Adarsh Swain

🔗 The website is fully responsive, ensuring a seamless experience across devices.

## Features

- **Fully Responsive**: The website is designed to work across all screen sizes and devices.
- **Navigation**: An interactive navigation bar with a hamburger menu for mobile screens.
- **Dynamic Content**: Links to various domains and event schedules.
- **Mentorship Info**: Displaying perks such as mentorship, badges, and certification.
- **Engaging Design**: Custom animations and icons to enhance the user experience.
- **FAQs Section**: Comprehensive FAQs to address common questions.

## Tech Stack

- **HTML5**: The latest version of HyperText Markup Language, used for structuring content on the web. HTML5 provides semantic elements, multimedia support, and APIs for better performance and functionality.
- **CSS3**: Used for styling and layout, CSS3 offers advanced features like flexbox, grid, media queries, and animations to create responsive and dynamic designs.
- **SCSS**: A CSS preprocessor that provides variables, nesting, and other useful features to make writing styles more efficient and maintainable.
- **JavaScript**: For DOM manipulation and interactivity.
- **Font Awesome**: For icons.

This now includes a description for **HTML5**!
## Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:Swayam2004/Skills-Clone.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Skills-Clone/dist/
   ```

3. Open the `index.html` file in your browser to view the project:
   ```bash
   open index.html
   ```

## Usage

- **Register**: Navigate to the registration page by clicking the "Register" button.
- **Explore Domains**: View various domains offered during the Skills++ event.
- **FAQ**: Visit the FAQs section for common questions and answers.

### Scripts

- The website includes a `goToRegister()` function that navigates users to the registration page.
- The `showSidebar()` and `hideSidebar()` functions toggle the sidebar visibility for mobile users.
